Fraud Detection Flow

1
Warehouse packs parcel → logs weight, dims, RFID, X-ray image → parcel gets UUID
2
Courier picks up → scans RFID → uploads parcel photo at each checkpoint
3
Customer receives → visits customer portal → uploads unboxing photo/video
4
AI Engine runs: image comparison + weight/dim delta + RFID check → fraud score computed
5
System pinpoints: if discrepancy between packing ↔ courier checkpoint → courier fraud. If packing ↔ customer photo → seller fraud
6
Trust scores updated. If score > threshold → auto-inquiry opened

Fraud Attribution Logic

A
Seller Fraud: Packed item image ≠ customer received image but courier checkpoints show no tampering → seller packed wrong/fake item
B
Courier Fraud: Packed item matches packing photo ✓ but courier checkpoint photo ≠ packing photo → item tampered in transit
C
Weight/Dim Fraud: Declared weight at packing ≠ courier scan weight → possible content swap or label fraud
D
RFID Mismatch: RFID tag at delivery ≠ tag logged at packing → parcel substitution attack
E
Combined Signal: Fraud score = weighted sum of all signals. Each signal contributes evidence to the inquiry case

🧠 Key Architecture Decisions

Monolith-First API
Single FastAPI app with clear module separation. Routes split by domain. Easy to demo, easy to scale later into microservices.
Customer Portal = Separate App
Port 3001, different origin. Communicates via public REST API with CORS headers. Simulates real-world B2C surface.
ResNet50 Embeddings
Pre-trained on ImageNet. Extract 2048-dim feature vectors. Cosine similarity for image comparison. No training needed → hackathon fast.
Weighted Fraud Score
Image delta 40% + weight delta 25% + RFID match 20% + dimension delta 15%. Score 0–100. Thresholds: >70 = High Risk.
UUID Parcel Tracking
Each parcel gets UUID at packing. RFID maps to UUID. QR code on parcel links customer portal to specific parcel record.
Local File Store (Hackathon)
Images stored in uploads/ directory. Path stored in DB. Production-ready swap to S3 with one config change.
