🐳
/docker-compose.yml
docker-compose.yml
Orchestrates all 4 services: postgres, backend, frontend, customer-portal. One command to run the entire system: docker-compose up

Services defined

  • postgres — Official postgres:15 image, volume mounted for data persistence
  • backend — Python FastAPI, depends on postgres, mounts uploads/ volume
  • frontend — Vite dev server, port 3000, env VITE_API_URL=http://localhost:8000
  • customer-portal — Vite dev server, port 3001, env VITE_API_URL=http://localhost:8000

Hackathon tip

# Run everything with one command: docker-compose up --build # Or run backend only (no Docker): cd backend && uvicorn app.main:app --reload
🚀
/backend/app/main.py
main.py
FastAPI app entrypoint. Creates the app instance, registers all routers, configures CORS (critical for customer-portal cross-origin requests), mounts static file serving for uploads.

What it does

  • Creates FastAPI() app with title, description, version
  • Adds CORSMiddleware — allows origin http://localhost:3001 (customer portal)
  • Includes all routers with /api prefix
  • Mounts /uploads as static files
  • @app.on_event("startup") creates DB tables

Skeleton preview

from fastapi import FastAPI from fastapi.middleware.cors import CORSMiddleware from app.routers import parcels, fraud, verification ... app = FastAPI(title="ParcelGuard API", version="1.0") app.add_middleware(CORSMiddleware, allow_origins=["*"], ...) app.include_router(parcels.router, prefix="/api/parcels") app.include_router(fraud.router, prefix="/api/fraud")

/backend/app/services/ai_engine.py
ai_engine.py
The brain of ParcelGuard. Loads ResNet50 (pre-trained), extracts image embeddings, computes cosine similarity between packing/courier/customer photos. Returns image delta score 0–1.

Exports

  • get_embedding(image_path) → torch.Tensor [2048-dim]
  • compare_images(path_a, path_b) → float (similarity 0–1)
  • load_model() → singleton ResNet50 instance

How it works

# 1. Load ResNet50 (no final classification layer) model = resnet50(pretrained=True) model = nn.Sequential(*list(model.children())[:-1]) # 2. Preprocess image → normalize → forward pass embedding = get_embedding("uploads/parcel_photos/abc.jpg") # 3. Cosine similarity between two embeddings score = F.cosine_similarity(emb_a, emb_b) # score ~1.0 = same item, score ~0.3 = very different

/backend/app/services/fraud_detector.py
fraud_detector.py
Combines all signals into a final fraud score and determines attribution (seller vs courier). This is where the business logic lives.

Fraud Score Formula

score = ( image_delta * 0.40 # AI image comparison + weight_delta * 0.25 # weight mismatch + rfid_flag * 0.20 # RFID mismatch + dim_delta * 0.15 # dimension mismatch ) * 100 # Attribution: # packing→courier mismatch → COURIER_FRAUD # packing→customer mismatch (chain ok) → SELLER_FRAUD

/customer-portal/
customer-portal/ ★ SEPARATE APP
Completely separate Vite + React app on port 3001. This is the public-facing website customers visit after receiving their parcel. It communicates with the main backend (port 8000) via REST API. Different origin = CORS enforced.

Why separate?

  • Simulates real-world B2C portal (different domain in production)
  • No auth required — public access with parcel UUID/QR code
  • CORS validation tests the API security model
  • Can be deployed independently (Vercel, Netlify, etc.)

Pages

  • / — Home (enter tracking ID or scan QR)
  • /verify/:parcelId — Upload photo/video of received parcel
  • /status/:claimId — Check fraud investigation status

Demo dataset for the hackathon. Seeds 10 sellers, 8 couriers, 50 parcels, 12 fraud events with realistic geolocation data for the heatmap. Run this for a fully populated demo.
