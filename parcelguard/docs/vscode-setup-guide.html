2
Open the workspace in VS Code
Open the .code-workspace file — not just the folder. This sets up all four root folders correctly.
# From terminal, inside the parcelguard/ folder:
code parcelguard.code-workspace
ℹ️ Why a workspace file? It sets up four sub-folders as separate roots (root, backend, frontend, customer-portal), so the Python interpreter, ESLint paths, and debug configs all resolve to the right directories automatically.

Step 3Set up the database

4
Create the PostgreSQL database
# In your terminal (not VS Code terminal yet):
psql -U postgres
-- then inside psql:
CREATE DATABASE parcelguard;
\q
⚠️ On macOS with Homebrew PostgreSQL: your default user may not be postgres. Run psql -U $(whoami) instead, or create a postgres user: createuser -s postgres

Step 4Configure the backend

5
Create your .env file
Copy the example and edit your database credentials:
cd backend
cp .env.example .env
# Then open .env and update DATABASE_URL with your postgres password
# backend/.env — the important line:
DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@localhost:5432/parcelguard
6
Select the Python interpreter in VS Code
Press Cmd/Ctrl + Shift + P → Python: Select Interpreter → choose the one inside backend/venv/ (if venv already created) or choose + Create Virtual Environment.
✓ Tip: The workspace settings already point python.defaultInterpreterPath to backend/venv/bin/python. After creating the venv (next step), VS Code will use it automatically.

Step 5Run everything with VS Code Tasks

7
First-time setup — install all dependencies
Press Cmd/Ctrl + Shift + P → Tasks: Run Task → choose:
🔧 First-time setup (install all deps)
This runs three things in sequence: creates Python venv + installs pip deps, then npm install for both frontends. Takes 2–5 minutes.
⚠️ PyTorch note: torch and torchvision are large (~800MB). The first pip install will take a few minutes. ResNet50 model weights (~100MB) download automatically on the first fraud analysis run.
8
Run database migrations + seed demo data
# Run these tasks in order (Tasks: Run Task → pick each one):
🗄️ Backend: Run migrations
🌱 Backend: Seed demo data
Migrations create all 7 tables. Seed data loads 15 sellers, 10 couriers, 30 parcels, 12 fraud events, and 5 investigation cases.
9
Start all three servers at once
Press Cmd/Ctrl + Shift + B (default build task) or via Tasks: Run Task:
🚀 Start ALL servers
This launches all three in parallel — each in its own dedicated terminal panel inside VS Code.

Step 6Debugging

10
Debug the FastAPI backend
Press F5 or go to Run → Start Debugging → select ⚡ Debug FastAPI. Set breakpoints in any router or service file — they'll hit when you make API requests.
✓ Pro tip: Use the 🚀 Full Stack (Backend + Chrome) compound config to launch the FastAPI debugger AND a Chrome debug window pointed at :3000 simultaneously — set breakpoints in both Python and JS.

Step 7Test the API with REST Client

11
Use api.http to send requests without leaving VS Code
Open api.http in the root folder. With the REST Client extension, every request block shows a clickable Send Request link above it.
### List all parcels
GET http://localhost:8000/api/parcels?limit=10

### Trigger fraud analysis
POST http://localhost:8000/api/fraud/analyze/{{parcel_id}}
ℹ️ Set @parcel_id at the top of the file to a real UUID from your seeded data. Find IDs at localhost:8000/docs → GET /api/parcels.

Common issuesTroubleshooting

❌ "relation does not exist" — database error on startup
Migrations haven't run yet. Run the 🗄️ Backend: Run migrations task, then restart the backend.
❌ Python: "ModuleNotFoundError: No module named 'app'"
PYTHONPATH isn't set. The VS Code workspace settings handle this automatically — make sure you opened the .code-workspace file, not just the folder. Alternatively run: export PYTHONPATH=$(pwd) in the backend terminal before starting uvicorn.
❌ Frontend: "Failed to fetch" / CORS error in browser console
The backend isn't running, or it started on a different port. Check the FastAPI terminal for errors. The Vite proxy (in vite.config.js) forwards /api to localhost:8000 — only works during npm run dev.
❌ "psycopg2.OperationalError: could not connect to server"
PostgreSQL isn't running. On macOS: brew services start postgresql@15. On Linux: sudo service postgresql start. On Windows: open Services and start PostgreSQL.
❌ VS Code shows the wrong Python interpreter
Cmd/Ctrl+Shift+P → Python: Select Interpreter → navigate to backend/venv/bin/python (macOS/Linux) or backend\venv\Scripts\python.exe (Windows).
