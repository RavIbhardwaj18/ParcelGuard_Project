Core Algorithm

Fraud Scoring Engine

Every parcel gets a 0–100 fraud score computed from four weighted signals. Scores above 70 trigger automatic investigation.

fraud_score = (0.40 × image_anomaly) + (0.25 × weight_delta)
             + (0.20 × rfid_mismatch) + (0.15 × dimension_variance)
40%
🖼️ Image Similarity
ResNet50 embeddings compared between packing X-ray and received-item photo. Cosine similarity < 0.5 = high risk.
25%
⚖️ Weight Delta
Declared vs. scanned weight at each checkpoint. > 0.5 kg deviation contributes proportionally.
20%
📡 RFID Match
Binary — tag scanned at delivery must match the tag attached at packing. Any mismatch = full contribution.
15%
📐 Dimensions
Package dimensions checked at each hub scan. > 15% variance is flagged.
0–29 Clean
30–49 Low — logged
50–69 Medium — flagged
70–84 High — inquiry opened
85–100 Critical — escalate

Trust Scoring

Reputation as a Deterrent

Trust scores start at 80.0. They climb slowly with clean deliveries and drop sharply when fraud is confirmed. Scores below 40 are auto-flagged. Couriers below 25 are recommended for suspension.

+1.5
Clean delivery streak (every 5 parcels)
−3.0
LOW fraud detected
−5.0
MEDIUM fraud detected
−15.0
HIGH fraud confirmed
−25.0
CRITICAL fraud confirmed

Getting Started

Quick Start

# 1. Database
createdb parcelguard

# 2. Backend
cd backend && pip install -r requirements.txt
alembic upgrade head && python -m seed.seed_data
uvicorn app.main:app --reload --port 8000

# 3. Ops frontend → http://localhost:3000
cd frontend && npm install && npm run dev

# 4. Customer portal → http://localhost:3001
cd customer-portal && npm install && npm run dev

# API docs → http://localhost:8000/docs
